# Drawback Chess

Jeu d'échecs avec défis inspiré de Drawback Chess. Jouable en local ou en ligne.

## Installation

```bash
npm install
```

## Lancement

```bash
npm start
```

Puis ouvrir http://localhost:3000

## Mode en ligne

1. **Créer une partie** : Choisissez les difficultés, cliquez sur "Créer une partie", partagez le code à 6 caractères.
2. **Rejoindre** : Entrez le code reçu et cliquez "Rejoindre".
3. Une fois l'adversaire connecté, le créateur clique sur "Lancer la partie".

Les deux joueurs doivent être sur le même réseau ou utiliser une URL publique (ex: ngrok, déploiement).
